The citizen authenticates via the We Are PIMS HTI launch. The PIMS issues an HTI token (JWT) containing the citizen's Web ID, which is exchanged with the back-end. Pod access is then arranged with client authentication only — no user OIDC session is required. The steps below mirror the "02. HTI flow" folder of the Postman collection.

  1. 1

    Fetch the HTI launch URL

    The back-end builds the We Are PIMS HTI launch URL, using its own /hti/capture endpoint as the redirect URI so the token is captured automatically.

    Launch URL: {{ htiLaunchUrl }}

  2. 2

    Get the HTI token via browser

    Opens the We Are PIMS HTI launch page in a new tab. After logging in, the PIMS shows the HTI token to paste in the next step.

    Navigates to the We Are PIMS HTI launch page. After logging in, the PIMS automatically submits the HTI token back to the back-end, which brings you straight back here once the Web ID has been captured.

  3. 3
